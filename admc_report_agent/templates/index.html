Asana Integration

Used to fetch deliverables from Asana. How to get a token?

  1. Go to https://app.asana.com/0/my-apps
  2. Click + Create new token
  3. Give it a name like ADMC Report Agent
  4. Copy the token (you will not see it again)
  5. Paste it in the field above
  6. The agent will search your workspace for matching client projects
The token gives read access to your Asana workspace. Store it securely.
